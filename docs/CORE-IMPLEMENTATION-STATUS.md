# Состояние реализации ядра

## C03 — контракт результатов: начато

Добавлены функция формирования идентификатора из явного ID правила и якоря и группировка наблюдений по этому идентификатору. ID не зависит от запуска или viewport. Это подготовительные компоненты: к отчётам они пока не подключены, поэтому дедупликации в продукте ещё нет.

Остаются: надёжные якоря отдельных элементов (текущий axe записывает несколько элементов одной записью), схема и валидация отчёта, наблюдения, совместимость старой истории и интеграционные проверки. До их выполнения C03 не считается завершённой.

Проверено: `test:runner` 25/25, `cargo test` 4/4, `npm run build`, `smoke` 5/9 с ожидаемыми дефектами, `test:fix` 9/9 и `test:edge` успешно. Эти проверки не подтверждают работу нового контракта в реальном отчёте.
