# Состояние реализации ядра

## C03 — контракт результатов: начато

Добавлены функция формирования идентификатора из явного ID правила и якоря и группировка наблюдений по этому идентификатору. Новый JSON-отчёт дополнительно содержит `normalizedFindings` для отдельных узлов axe и `normalizedCoverage: partial`. Старые поля `issues` не изменены. ID не зависит от запуска или viewport; наблюдения сохраняют отдельные ID и ссылки на скриншоты.

Добавлена схема расширения `runner/schemas/normalized-report-v0.1.schema.json` и runtime-проверка связности этого расширения перед записью отчёта. Исторические отчёты без версии расширения принимаются без изменения; это не полная миграция. JSON Schema описывает структуру, а дополнительные проверки ID и уникальности выполняются кодом.

Остаются: нормализация остальных типов находок, более надёжные семантические якоря (CSS-селектор может измениться при перестройке страницы), полная схема отчёта, валидация истории при чтении и интеграционные проверки. Узлы без поддерживаемого селектора пропускаются. До выполнения этих задач C03 не считается завершённой.

Проверено: `test:runner` 32/32, `cargo test` 4/4, `npm run build`, `smoke` 5/9 с ожидаемыми дефектами, `test:fix` 9/9 и `test:edge` успешно. В двух предыдущих отчётах Relay ID контраста совпал, а четыре наблюдения каждого прогона имели отдельные ID. Новый отчёт с runtime-проверкой: `.uxproof-data/runs/df9c60bf-fca3-4520-b009-ffe24fa0c715/report.json`.

## C04 — сравнение: начато

Добавлена отдельная функция сравнения одинаковых идентификаторов при наличии одинакового ключа конфигурации. Ключ новых отчётов учитывает URL, сценарии, размеры и опции; старые отчёты без ключа не считаются сопоставимыми. Сводное сравнение в интерфейсе показывается только для завершённых прогонов с одинаковым ключом. Несовпадения отдельных ID помечаются `unverified`, в том числе при полном покрытии: перемещение элемента может изменить селектор. Сравнение отдельных ID не подключено к интерфейсу и не поддерживает fuzzy matching или историю регрессий. C04 не завершена.
