# Состояние реализации ядра

## C03 — контракт результатов: начато

Добавлены функция формирования идентификатора из явного ID правила и якоря и группировка наблюдений по этому идентификатору. Новый JSON-отчёт дополнительно содержит `normalizedFindings` для отдельных узлов axe и упавших шагов Playwright, а также `normalizedCoverage: partial`. Старые поля `issues` не изменены. ID не зависит от запуска или viewport; наблюдения сохраняют отдельные ID и ссылки на скриншоты.

Добавлены схемы расширения `runner/schemas/normalized-report-v0.1.schema.json` и `normalized-report-v0.2.schema.json` и runtime-проверка связности этого расширения перед записью отчёта. Исторические отчёты без версии расширения принимаются без изменения; это не полная миграция. JSON Schema описывает структуру, а дополнительные проверки ID и уникальности выполняются кодом. Runtime-проверка реализована вручную, не через движок JSON Schema.

Остаются: нормализация остальных типов находок, более надёжные семантические якоря (CSS-селектор может измениться при перестройке страницы), полная схема отчёта, валидация истории при чтении и интеграционные проверки. Узлы без поддерживаемого селектора пропускаются. При изменении сценария fingerprint упавшего шага меняется; это намеренно консервативное сопоставление, а не подтверждение исправления. До выполнения этих задач C03 не считается завершённой.

Проверено: `test:runner` 34/34, `cargo test` 8/8, `npm run tauri build`, два `smoke` 5/9 с ожидаемыми дефектами, `test:fix` 9/9 и `test:edge` успешно. В двух новых отчётах Relay все ID нормализованных находок совпали; три упавших шага настроек объединены с отдельными наблюдениями. Проверена схема v0.2 через Python jsonschema. Пример: `.uxproof-data/runs/fb932492-aed3-4f2e-bd2e-1231066f72e8/report.json`.

## C01 — Tauri E2E: не завершено

Окно Tauri открывалось, но запуск через кнопку и последующие действия не проверены. Попытка управления окном была остановлена средством Computer Use из-за ограничения политики URL.

## C04 — сравнение: начато

Добавлена отдельная функция сравнения одинаковых идентификаторов при наличии одинакового ключа конфигурации. Ключ новых отчётов учитывает URL, сценарии, размеры и опции; старые отчёты без ключа не считаются сопоставимыми. Сводное сравнение в интерфейсе показывается только для завершённых прогонов с одинаковым ключом. Несовпадения отдельных ID помечаются `unverified`, в том числе при полном покрытии: перемещение элемента может изменить селектор. Сравнение отдельных ID не подключено к интерфейсу и не поддерживает fuzzy matching или историю регрессий. C04 не завершена.

## C05 — блокировка IPC: частично

В Rust добавлена блокировка аудита на время рабочего процесса и файловая блокировка между экземплярами Tauri с общей папкой app-data. Guard передаётся рабочему потоку и освобождается при завершении или ошибке. Тест Rust проверяет отказ второго процесса, повторный запуск после освобождения, параллельные потоки и освобождение при ошибке и panic. Блокировка web dev API остаётся отдельной; полноценная проверка IPC в окне, тесты упаковки и остальные задачи C05 ещё не выполнены.

## C08 — приватность: частично

Конфигурация нового Tauri-запуска передаётся runner через stdin вместо записи `input.json`. Старые файлы не удаляются автоматически. Снимки маскируют поля ввода, редактируемые области, iframe, canvas и видео; одни и те же маскированные PNG получены при изменении тестовых значений полей, iframe и canvas. Ошибки проверок текста и значения не выводят ожидаемое или фактическое значение; интеграционный тест проверил отсутствие тестовых значений в JSON и HTML. Реальный CLI через stdin выполнил один сценарий Relay (`.uxproof-data/runs/197a26d1-dd8f-44a6-afa6-6fe78dfa96e9`).

Остаются: обнаружение и редактирование секретов в обычном тексте страницы, сообщениях JavaScript, URL, именах сценариев и других источниках; маскирование не является гарантией отсутствия секретов. Передача в модель использует тот же снимок, но полный тест с живой моделью не выполнен. Отчёт предупреждает об ограничении. Скрытые iframe, canvas и видео снижают полноту визуального доказательства; C08 не завершена.
