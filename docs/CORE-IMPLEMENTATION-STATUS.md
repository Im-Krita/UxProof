# Состояние реализации ядра

## C03 — контракт результатов: начато

Добавлена функция формирования идентификатора из явного ID правила и якоря; ID не зависит от запуска или viewport. Это подготовительный компонент, он пока не подключён к отчётам и не выполняет дедупликацию.

Остаются: надёжные якоря отдельных элементов (текущий axe записывает несколько элементов одной записью), схема и валидация отчёта, наблюдения, совместимость старой истории и интеграционные проверки. До их выполнения C03 не считается завершённой.

## C01 — Tauri E2E: не завершено

Окно Tauri открывалось, но запуск через кнопку и последующие действия не проверены. Попытка управления окном была остановлена средством Computer Use из-за ограничения политики URL.
