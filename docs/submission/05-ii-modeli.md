# ИИ в UXProof

ИИ выключен по умолчанию (`enableAI: false`). Основной аудит (шаги, axe, overflow, pageerror, PNG) работает без ключа и без Ollama.

Две роли, оба вызова необязательны.

## Vision-ревью скриншота

Файл: `runner/ai.mjs`. Модель получает PNG и короткий контекст сценария. Ответ: JSON до трёх замечаний. Класс в отчёте только `recommendation`. Промпт запрещает называть гипотезы доказанными ошибками и оценки в процентах.

| Провайдер | Переменная модели | Дефолт в коде | Что гоняли 19.11.2026 |
|---|---|---|---|
| Ollama, `http://127.0.0.1:11434/api/chat` | `UXPROOF_OLLAMA_MODEL` | `llava` | `qwen2.5vl:3b` через `npm run qa:ollama` |
| OpenAI Responses API, `store: false` | `UXPROOF_AI_MODEL` | `gpt-4.1-mini` | живой платный вызов не делали |

Ollama: только loopback. Чужой хост отклоняется. Ключ OpenAI берётся из `OPENAI_API_KEY` окружения процесса, не из UI и не из `VITE_*`.

Не больше трёх вызовов модели за прогон. HTTP-ошибка провайдера не валит аудит: появляется предупреждение, технические проверки остаются.

`moondream` на реальном экране Relay уходил в повтор токенов и HTTP 500. Для QA его не используем.

## Черновик шагов

Файл: `runner/planner.mjs`. Текст цели → JSON шагов → `sanitizePlan` → тот же `validateConfig`, что у редактора. Off-origin `navigate`, неизвестные типы и небезопасные значения отбрасываются. UI показывает превью; в сценарий список попадает только по кнопке.

| Провайдер | Переменная модели | Дефолт в коде | Что гоняли 19.11.2026 |
|---|---|---|---|
| Ollama | `UXPROOF_OLLAMA_MODEL` (та же, что у vision) | `llama3.1` | `qa:ollama` на время planner ставит `qwen2.5:3b` |
| OpenAI | `UXPROOF_PLANNER_MODEL` | `gpt-4.1-mini` | живой вызов не делали |

`UXPROOF_PLANNER_MODEL` на путь Ollama не действует. Если для Ollama не задать `UXPROOF_OLLAMA_MODEL`, planner возьмёт `llama3.1`. `llama3.2:1b` на стенде отвечал HTTP 500.

План не становится находкой и не запускается сам.

## Скриншоты и данные

Включённый OpenAI отправляет PNG во внешний API. Без согласия не грузить секреты, переписку, персональные данные. Локальный Ollama остаётся на машине.

Рекомендации ИИ субъективны. Их отсутствие или наличие не доказывает качество интерфейса.
