# Итоговый отчёт аудита UXProof

Дата: 15 ноября 2026. Машина: Windows 10 (10.0.19045), Node.js 24.14.1, npm 11.11.0, rustc 1.98.1, WebView2 157.0.4341.46.

Платный OpenAI не вызывался. Проверялся локальный Relay на `http://127.0.0.1:4180` и вариант `http://127.0.0.1:4180/fixed`.

## 1. Что удалось запустить

- Локальный Relay и его исправленный вариант `/fixed`.
- Веб-режим `npm run dev`: Vite на `http://127.0.0.1:1420` и API на `127.0.0.1:4179`.
- Реальный Playwright Chromium, 9 комбинаций сценарий×экран.
- Окно Tauri 2 (`target\debug\uxproof.exe`), заголовок «UXProof», интерфейс сценариев отрисован.
- Release: `src-tauri\target\release\uxproof.exe` (9 083 904 байт), MSI и NSIS.

## 2. Какие функции проверены

Создание и правка сценария, смена порядка шагов, запуск аудита, три размера экрана, падение шага с причиной, axe-core, исключение JavaScript, горизонтальный вылет, PNG, JSON, HTML, история, сравнение чисел с прошлым прогоном, отказ `file:` URL, отказ параллельного запуска, отказ шага `eval`, отказ чужого origin и адреса метаданных, отсутствие ключа OpenAI без поломки технического прогона. Подробная матрица: `docs/FEATURE-MATRIX.md`.

## 3–5. Ошибки

Обнаружено 15 записей. Исправлено 11 (`BUG-001`…`BUG-011`). Открыты 4, все некритичные или заранее известные ограничения MVP:

- `BUG-012` — установщик не содержит собственный Node и Chromium.
- `BUG-013` — живой OpenAI и запущенный Ollama не проверялись.
- `BUG-014` — кнопка запуска внутри окна Tauri не нажата.
- `BUG-015` — сравнение прогонов только по сводным числам.

Журнал: `docs/AUDIT.md`. Незакрытых критических уязвимостей после исправлений нет. Это не доказательство, что других дефектов нет.

## 6. Rust

`cargo test` в `src-tauri`: 4 теста валидации URL, шагов и имён файлов прошли. Затем `npm run tauri build` собрал release за 1 мин 12 с, код выхода 0.

## 7. React

`npm run build` (`tsc --noEmit && vite build`) прошёл дважды, последний раз как `beforeBuildCommand`. Свежие файлы: `dist/assets/index-W_XLinot.js`, `dist/assets/index-BGhQ4PuC.css`.

## 8. Tauri

`npm run tauri dev`: Vite поднялся, `Finished dev profile` за 12,23 с, процесс `uxproof.exe` отвечал, окно показало проект Relay и кнопку «Запустить аудит». После старта окна запросов к `/api` не было: вебвью не откатилось на dev API.

`npm run tauri build`, код 0:

- `src-tauri\target\release\uxproof.exe`
- `src-tauri\target\release\bundle\msi\UXProof_0.1.0_x64_en-US.msi` (7,57 МиБ)
- `src-tauri\target\release\bundle\nsis\UXProof_0.1.0_x64-setup.exe` (4,91 МиБ)

Рядом с release-exe лежит `runner\`, включая `playwright`. Сами установщики слишком малы, чтобы содержать Chromium. На другой машине без Node и браузера Playwright приложение не станет автономным.

## 9. Playwright

`npx playwright install chromium` скачал Chromium 159.0.8154.6.

- `npm run test:runner`: 22 теста, 0 падений.
- `npm run smoke`: 9 прогонов, 5 пройдено, 4 провалено, 18 подтверждённых дефектов, 0 рекомендаций ИИ.
- `npm run test:fix`: те же 9 прогонов на `/fixed`, 9 пройдено, 0 дефектов.
- `npm run test:edge`: `file:`, `eval`, замок, битый селектор останавливает следующие шаги, ИИ без ключа, path traversal 400, запрос без заголовка 403.

## 10. Доступность

Демо Relay: правило `color-contrast` на `.bad-contrast` есть в баговом прогоне и отсутствует после `/fixed`.

Само приложение UXProof: первый axe-прогон дал serious `color-contrast` и `label-content-name-mismatch`. После правки цветов и имени навигации повтор на сценариях, истории, пустых результатах и ширине 390px не нашёл нарушений и pageerror. Это не полный ручной WCAG-аудит.

## 11. Безопасность

Проверено и ограничено кодом:

- схемы не `http(s)`, логин в URL, `javascript:`, `169.254.169.254`;
- `navigate` только внутри origin проекта;
- запросы страницы к чужому loopback и частной сети, DNS-ответ в link-local;
- путь скриншота и HTML не выходит из каталога отчёта;
- локальный API слушает `127.0.0.1` и требует заголовок `X-UXProof-Client`;
- ключ OpenAI не попадает в текст ошибки и не требуется для аудита;
- удалённый Ollama отклоняется;
- команды IPC перечислены в capability, CSP больше не `null`;
- Rust не собирает shell-строку из URL.

Не делалось: атака на чужие публичные сайты, проверка установленного MSI на чистой машине, полный обход Tauri ACL кликом в окне.

## 12. Ограничения MVP

- Установщик не везёт Node и Chromium.
- Один запуск последовательный, без очереди и без снимка каждого шага.
- Сравнение прогонов — сводка, не diff картинок.
- ИИ выключен по умолчанию и в этом прогоне не получал ответ модели.
- Изоляция контекста не откатывает серверные данные проверяемого сайта.

## 13. Перед хакатоном

1. На стенде один раз нажать «Запустить аудит» в окне Tauri и открыть HTML через кнопку, чтобы закрыть `BUG-014`.
2. Не обещать автономный установщик. Показывать `npm run tauri dev` или заранее подготовленную машину с Node и Chromium.
3. Демонстрировать `/` и затем `/fixed`: 5/9 становится 9/9, три дефекта исчезают.
4. ИИ не включать, если нет своего ключа или локальной модели. Пустую рекомендацию не подменять.
5. Проговорить, что axe и отсутствие упавших шагов не означают полное WCAG и отсутствие UX-дефектов.
